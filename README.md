# 融税通 Agent

面向小微企业的财税合规与普惠融资准备度智能管家，参赛方向为 **AI + 金融**。

## 项目简介

融税通通过本地解析企业材料，将票据、银行流水、营业执照和财务报表转化为可核验的经营证据，并形成财税风险提示、融资资格预检和材料补充建议。系统区分事实、规则、推测与待确认事项，不直接替代会计师、税务机关或银行作出专业结论。

## 核心能力

- 企业名称与经办人身份建档
- PDF、图片、Excel、CSV、TXT 材料解析
- 图片中英文 OCR 与文本 PDF 信息抽取
- 银行流水、发票和财务报表关键字段汇总
- 财税异常线索与证据链展示
- 融资资格准备度预检及产品匹配
- 真实材料模式与合规演示样本模式隔离
- 测评报告与分析依据展示

## 合规设计

- 文件默认仅在当前浏览器中处理
- 识别结果需由用户确认后进入分析
- 输出定位为辅助预检，不构成审计、鉴证、纳税或授信结论
- 分析参考中国企业会计准则、小企业会计准则及相关财税监管要求
- 贷款额度、利率和审批结果以金融机构正式审查为准

## 技术栈

- Next.js / React / TypeScript
- vinext / Cloudflare
- SheetJS（Excel、CSV）
- PDF.js（文本 PDF）
- Tesseract.js（图片 OCR）
- Drizzle ORM（可选数据层）

## 本地运行

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 项目结构

```text
app/                 页面、样式、文件解析与测评逻辑
db/                  可选数据库结构
public/              静态资源
tests/               渲染测试
worker/              Cloudflare Worker 入口
.openai/hosting.json 部署配置
```

## 重要声明

本项目为竞赛原型。真实业务部署前仍需完成等保、隐私影响评估、数据授权管理、规则库版本治理、人工复核机制及持牌机构系统对接。
